Why so much of this is optional

A bundle carries its own pictures, sounds and dialogue, so the only things a render truly needs are the renderer, the media inspector, somewhere to keep files and a database. Everything else on this list buys convenience: yt-dlp fetches captions from a link, Piper reads dialogue aloud, whisper.cpp writes a transcript from audio.
