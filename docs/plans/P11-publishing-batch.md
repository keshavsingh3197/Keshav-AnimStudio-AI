# P11 — Publishing and batch

Turns one rendered file into everything needed to publish it, and one URL into many.

---

## Actions

### A11.1 — Export presets and auto-reframe
16:9, 9:16, 1:1 and 4:5 from one project. Reframing crops around a subject-safe area
computed from sprite placements (the app already knows where the characters are, so no
detection model is needed). Each preset is a separate render job sharing the same plan.

### A11.2 — Thumbnail and metadata pack
Thumbnail: pick the highest-contrast frame from the highest-intensity scene, overlay a
title from the style kit's type treatment. Metadata: title, description, tags and
chapters (segment boundaries are already there), generated by `ITextAiProvider` with a
deterministic template fallback when no AI is configured.

### A11.3 — Subtitle sidecars
SRT and VTT export alongside the burned-in ASS, from the same cue data. Per-language when
P11.5 is used.

### A11.4 — Batch runs
A playlist URL, a pasted list of URLs, or a spreadsheet column of URLs creates one
pipeline job per video, queued with a global concurrency cap and per-provider quota
awareness so a batch cannot exhaust a free tier in one minute. Batch view shows each run's
stage timeline.

### A11.5 — Multi-language dub
Translate the script (`ITextAiProvider`), synthesize per-language voices, emit per-language
subtitle tracks, and render one output per language. Voice mapping falls back to the
default voice for a language the provider does not carry.
